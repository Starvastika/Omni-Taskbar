# Interactive release gate

Record results from the exact EXE-installed build on an isolated Windows 11 desktop. Do not mark a case passed from source inspection or a prepared workflow. Publish only after the complete matrix passes.

- Two grayscale bars, visible icons, tray overflow, notification/control/account surfaces.
- Native Start, taskbar grouping/activation/minimized sibling windows and virtual desktop switching.
- Floating window and desktop persistent top bar; work-area placement of new/restored/secondary windows.
- Maximized and Windows Snap hidden at rest, top hover reveals only after reservation/reflow; restore state retained.
- F11, borderless/windowed/true fullscreen: no top-edge reveal/reservation/input strip. Repeated browser tab interaction.
- Compact weather Setup location opens real Locations search and focuses it; selection/change updates both surfaces; offline preserves selected identity; no developer locations shipped.
- Time Center map wrapping, clocks/calendar/timers/stopwatch/alarms/planner, retained preferences and state.
- Weather Center pages/layers/radar/charts/navigation/settings and Time Center integration.
- Existing ... popup: Taskbar Updates immediately below Manage accounts; no extra permanent update icon.
- Available/staged/manual-found/failed/rolled-back red indicators persist across popup open/close; successful update clears attention.
- All three modes selectable/persisted; manual no unsolicited checks; automatic staging applies at safe shell restart without reboot.
- Fresh install / repair / manual upgrade / default uninstall / explicit data removal; autostart and single watchdog.
- Real installed-layout success update and broken-update rollback; startup health and post-rollback feature matrix.

CI automation supplements this matrix; it does not stand in for physical UI coverage.
